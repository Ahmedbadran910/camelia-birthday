CAMELIA'S FIRST BIRTHDAY INVITATION
====================================

The invitation now includes Camelia's photo, the supplied birthday date,
the Gezira Youth Center Club location link, and the WhatsApp RSVP number.

TO PREVIEW
1. Extract this ZIP file.
2. Open index.html in Chrome, Edge, or Firefox.

TO UPDATE THE PARTY TIME
1. Open script.js.
2. In CONFIG, replace dateTime with the party start time:
   YYYY-MM-DDTHH:MM:SS
3. Replace timeLabel with the time guests should see.
4. Save and refresh index.html.

PUBLISH FREE WITH GITHUB PAGES
1. Sign in to GitHub and create a public repository, e.g. camelia-birthday.
2. Upload all files and folders from this ZIP.
3. Open repository Settings > Pages.
4. Under Build and deployment, choose Deploy from a branch,
   branch main, folder /(root), then Save.
5. GitHub will provide a public invitation URL.

The countdown currently counts down to the beginning of Friday 20 November
2026 because the exact party time has not yet been provided.
